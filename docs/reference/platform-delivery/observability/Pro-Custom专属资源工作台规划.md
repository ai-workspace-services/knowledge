# Pro Custom 专属资源工作台规划

日期：2026-11-03。状态：待实现、待验收。需求：[Knowledge #351](https://github.com/ai-workspace-services/knowledge/issues/351)。[完整规划](Pro-Custom与Grafana升级完整规划.md) · [交付验收](Pro-Custom与Grafana分阶段交付验收规划.md) · [目录](README.md)

## 1. 范围与入口

仅替换侧边栏“用户高级配置选型”下的四个页面内容，为 Pro Custom 提供专属节点工作台。保留现有面板外壳、导航样式、其他模块与非目标用户行为。不重做全站，不调整套餐价格，不顺带替换网关或集群。

| 路由 | 目标行为 | 实现边界 |
| --- | --- | --- |
| `/panel/deployments` | 自助创建专属节点、跟踪创建任务 | 服务端目录、报价、权益、幂等与异步任务 |
| `/panel/resources` | 查看自己的专属节点与详情 | 服务端按客户空间及节点归属过滤 |
| `/panel/observability` | 直接展示对应用户的 Grafana Dashboard | Portal 只管入口和身份，图表由 Grafana 维护 |
| `/panel/api-keys` | 保留入口及“开发中”说明 | 未来接入 AI 网关，当前无密钥读写 |

四路由目前复用占位组件；实施时建立独立页面 loader，保留其他调用者，包括 `/panel/settings`。`/panel/api` 接口集成与 `/panel/api-keys` 不混为一页。

## 2. 权益和归属

访问新能力同时满足：有效登录、当前客户空间成员关系、有效 Pro Custom 权益、操作权限，以及目标节点归属。只读成员无创建权限。管理员角色不能被浏览器用来绕过客户数据边界。

具体 plan ID 由账户服务目录确认；不得把假定的 `PRO-CUSTOM` 字符串当成现有生产事实。推荐由服务端返回能力、有效期、节点额度、已用/预留数量及允许区域/规格。套餐、成员权限、资源归属按交集判定，不因其中任意一项命中就全部放行。

导航与页面判断用于交互，所有 API 独立验证。权益读取失败时不展示可操作创建入口，不将未知状态当作套餐有效；非目标用户继续沿用原有行为。订阅降级或到期后的资源保留/只读规则由产品另行确认，本轮不自动销毁节点。

## 3. 部署管理

流程：选择区域与规格 → 节点名称/标签 → 服务端报价和配额校验 → 用户确认 → 创建任务 → 查看进度 → 打开资源详情。

名称、备注、标签仅作业务元数据，不允许用户直接提交 provider 凭据、任意脚本、镜像、SSH 命令或库存文件。可售目录由后端产品与资源 owner 提供。

费用展示应包括计费周期、币种、资源和托管费用、预计总价及报价有效期。尚未确定费用/额度契约时，创建入口保持不可执行，不填假价格。最终确认使用服务端报价标识；过期或变更需重新确认。

任务采用服务端幂等键。相同客户与请求重复提交返回同一任务；并发请求原子预留额度，避免超配。任务返回后页面可刷新或离开，重新打开能继续查询；超时表示状态未知，不默认再次创建。

| 阶段 | 用户可见内容 | 失败处理 |
| --- | --- | --- |
| 接收/校验 | 请求编号、配额结果 | 明确不可创建的原因 |
| 排队/创建 | 当前阶段、更新时间 | 受控重试，先查询资源是否已产生 |
| 服务初始化 | 节点与服务就绪进度 | 保存部分成功资源与失败回执 |
| 监控接入 | 等待首次指标 | 不阻塞显示已存在节点，不伪装监控成功 |
| 完成 | 节点详情和监控入口 | 资源与监控状态分别报告 |

任务取消、节点删除、重建、改规格与自动退款不属于首期默认功能。失败后的计费和预留额度释放按实际结果处理，存在资源时不能盲目释放全部预留并自动重建。

## 4. 资源列表与详情

列表显示名称/稳定节点 ID、区域、规格、运行状态、创建时间、最后同步时间、监控状态。支持当前客户范围内的搜索、状态/区域筛选与分页。详情显示资源基本信息、最近任务和“查看监控”。

空态引导到部署管理；加载、权限失效、数据过期和上游不可用分别展示。接口失败不显示为“没有节点”。用户切换空间时清理前一空间数据，缓存键包含客户空间，服务端响应禁止跨租户共享缓存。

节点运行、服务健康、指标新鲜度分别建模。节点运行但监控未接入时显示“运行中 / 监控准备中”；监控断流不直接等同主机宕机。详情访问和任务查询也验证归属，不能只过滤列表。

## 5. 可观测性与接口密钥

可观测性直接嵌入 Grafana 专属节点总览，提供节点筛选、时间范围、刷新和打开完整 Grafana 的入口。组织准备中、无节点、待首次指标、无权限、数据源异常、嵌入失败均有独立状态。实际隔离见[租户方案](Grafana租户隔离与Portal嵌入规划.md)。

接口密钥保留导航与“开发中：未来对接 AI 网关”。不展示测试 Token，不提供创建、复制、轮换、删除，不因此申请额外平台密钥权限。

## 6. 待实现 API 契约

下表描述能力与字段，不宣称已有 API，不预设未经 owner 评审的路径。

| 能力 | 最小输出/输入约束 |
| --- | --- |
| 当前权益与目录 | 可用能力、区域、规格、额度、版本与有效期 |
| 报价 | 规格、周期、明细、报价 ID、到期时间 |
| 创建任务 | 报价 ID、业务字段、幂等键；返回任务 ID |
| 查询任务 | 状态、阶段、更新时间、节点 ID、脱敏错误、重试建议 |
| 节点列表/详情 | 稳定 ID、归属、状态、规格、同步时间、监控状态 |
| 当前观测上下文 | 当前客户绑定与允许 Dashboard；不接受任意客户 ID |

用户与客户空间从可信会话解析。所有写接口有请求来源/CSRF 校验与审计；审计保存请求 ID、身份、目标、阶段和结果，不保存凭据。查询频率、任务轮询退避和后端限额在接口设计时确定。

## 7. 页面验收

- Pro Custom 完成一次真实的授权测试节点创建，任务刷新后可继续查询；重复提交不产生第二节点。
- 并发请求不超过配额，报价过期可识别，失败部分资源可追溯。
- 客户 A 无法通过节点 ID、任务 ID、缓存、分页或空间切换读取 B。
- 新节点出现在资源列表，首次指标到达后观测状态改变，Grafana 同范围展示。
- 普通用户、非目标套餐、只读用户、原有管理员页面和 `/panel/api` 回归通过。
- 接口密钥仅显示开发中；本轮文档交付不构成上述运行验收。
