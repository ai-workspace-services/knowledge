---
ch: 08
label: 第 8 章
title: 身份与安全
subtitle: Identity & Security · 1990s – 今
intro: 安全演进的本质，是信任边界不断上移：机器 → 网络位置 → 访问控制 → 身份 → 持续验证 → 模型能力 → 机器身份。
timeline:
- 1993：Kerberos v5（RFC 1510）/ LDAP
- 1994：Check Point FireWall-1
- 2000：Active Directory
- 2005：SAML 2.0
- 2010：Forrester 提出 Zero Trust
- 2012：OAuth 2.0（RFC 6749）
- 2014：OpenID Connect 1.0 / BeyondCorp
- 2015：JWT（RFC 7519）
- 2020：NIST SP 800-207 零信任架构
note: 本章金句：信任边界的终点，不是网络，也不是身份，而是能力本身。
