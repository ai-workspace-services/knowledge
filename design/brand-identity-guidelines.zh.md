## 一、 品牌双轨制架构体系 (Two-Tier Architecture)

本规范采用国际一流开源与企业级技术平台（如 Google、GitHub、Vercel、Figma）通行的**双轨制品牌视觉模型**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    XWork Technologies 双轨制品牌架构模型                    │
├─────────────────────────────────────────────────────────────────────────────┤
│  🏢 Level 1：组织级母体身份 (Corporate & ORG Master Mark)                    │
│  ─────────────────────────────────────────────────────────────────────────  │
│  【2×2 互锁方格 + XWork Technologies 字标】                                   │
│  • 定位：代表开放、中立、高性能、严谨可靠的云原生底层基础设施。               │
│  • 应用：官网 Header / Footer、GitHub Org 头像、企业控制台、商务凭据、SaaS SSO │
├─────────────────────────────────────────────────────────────────────────────┤
│  🤖 Level 2：产品级应用与伴侣 IP (Product Companion Universe)                 │
│  ─────────────────────────────────────────────────────────────────────────  │
│  • 🚀 XConnect：Swift-Ray (微笑飞鳐 + 悬垂脉冲球) — 全球网络加速客户端          │

│  • 纽带闭环：三款 APP 右下角均内嵌 Level 1 的 2×2 微型角标，100% 呼应母体！      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、 核心产品资产与设计语言拆解

### 1. 🏢 XWork Technologies 母体身份 (Corporate Identity)
- **几何构型**：正方形圆角 Squircle（圆角率 26%），内嵌 4 颗等距圆角小方块，呈现对角互锁排列（左上白、右上青、左下青、右下白）。
- **字标排版**：`XWork` 采用重磅黑体（Font Weight 900），代表坚不可摧的底层执行力；`Technologies` 采用常规灰蓝体（Font Weight 400，`#475569`），展现从容开放的科技生态。

### 2. 🚀 XConnect APP (Swift-Ray 极速飞鳐)
- **产品隐喻**：专为全平台（iOS/Android/macOS/Windows/Linux）AI 访问与跨云加速而生。飞鳐是在骨干网络中无阻滑翔的数据信使。
- **形态特征**：
  - 饱满圆润的下压式大机翼，破风前行；
  - 头部嵌入两颗深色专注椭圆眼；
  - 下腹部为一体化深海蓝微笑曲线，悬垂一颗浑圆的**心跳脉冲球（网络信号连接珠）**；
  - 右下角内嵌 2×2 品牌生态微标。

### 3. 🤖 XWorkmate APP (Worky-Bot 暖心工伴)
- **产品隐喻**：“对话即工作”，时刻倾听开发者与知识工作者需求的贴心 Pair Programmer。
- **形态特征**：
  - 婴儿身材比例的浑圆大头；
  - 头侧佩戴两只圆滚滚的半球形降噪耳罩（代表全天候深度倾听上下文）；
  - 奶白面罩内是一对温暖笑意的大黑豆点眼与柔和嘴部；
  - 右下角内嵌 2×2 品牌生态微标。

### 4. 🌌 AI Workspace 标志 (Cubo-Dock 全能母舱)
- **产品隐喻**：聚合智能与连接的开放工作空间底座，可私有化自建、可弹性云托管。
- **形态特征**：
  - 稳固耐看的方圆工作基座，象征扎实可靠的容器云基础设施；
  - 上方覆盖一体化大半球形通透观察穹顶（Observation Dome）；
  - **穹顶内部点亮一对好奇敏锐的翠绿色智核双眸（`#10B981`）**；
  - 基座下方带有长条形翠绿运行状态屏；
  - 右下角内嵌 2×2 品牌生态微标。

## 四、 极端像素表现规范 (32×32 Micro Legibility)

针对浏览器标签页（Favicon）、操作系统顶部菜单栏（macOS MenuBar）、任务栏角标等极小场景进行了专门像素对齐设计：
- **母标 Favicon**：四格微方块在 16px/32px 下保持 1px 清晰间隙，对角反差强烈。
- **XConnect 32**：提炼为极速青三角流线光矢剪影，一眼即识“网络加速”。
- **XWorkmate 32**：双外凸大耳罩剪影极具视觉抓力。
- **AI Workspace 32**：上方圆穹顶（带两点微像素绿光）加下方宽方座，轮廓高度辨识。
- **原则**：在 ≤32px 场景下，**自动隐去右下角微型角标**，确保主角色轮廓 100% 纯粹清晰。
