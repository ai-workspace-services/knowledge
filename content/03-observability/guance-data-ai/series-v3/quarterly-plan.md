# 观测云可观测性系列 · 季度排期（草案）

> 状态：草案，待评审，可能被另一版季度方案替换。起始周与具体发布日期【待确认】，下文用 W1–W12 相对周表示。

## 1. 目标与硬规则

- 12 周、每周 1 篇，公众号与小红书同步；顺序为 为什么 → 边界 → 怎么做 → 验证 → 回退/演进，第 12 篇回指第 1 篇，形成闭环。
- 每篇一个背景、一个痛点、一个方案，结尾一张决策表（功能 / 特性 / 成本 / 客观事实依据 / 适用场景）。相邻两篇模板不同。
- 实践主线统一为 AI 辅助的 IaC / GitOps / Playbook：
  - GitOps 只放非敏感环境参数与监控意图；
  - iac_modules renderer 把声明生成显式 HCL，Terraform 做 plan；
  - Playbook 部署 DataKit 与 OTel Collector 配置；
  - Vault 运行时注入凭据，管理 API Key、查询 Key、写入 Token 分开存放、分开授权，不进仓库与 CI 日志；
  - AI 起草声明、配置与 PR 说明，人审 PR 与 plan；
  - 首次开通与授权为人工前置。
- 正文不写任何控制台点击步骤。免费空间不支持 Open API，apply 被阻断，相关结果统一写【待授权空间实测】；其他未实测结果写【待实测】。
- 不署名，不写公司名，不写内容合作披露行；图中不放日期、授权说明、图注和【待实测】。
