# 迁移监控最怕回不去🔙

## P1 背景
接入、控量、日志、搬面板、对口径、告警、拨测都试过了。自建 VictoriaMetrics、VictoriaLogs、Grafana 一直在跑，观测云只是并行的新链路。

## P2 为什么要设计回退 ⚠️
免费空间数据 7 天循环；空间不能解散，Owner 不能移交；协议写了可提前 15 天通知终止服务。新链路出问题或要退出，必须能一键回去。

## P3 Step1 开关 + 双写 🎚️
开关默认关：只有一个 sink。打开：Vector/Collector 加第二个 sink 写 DataKit，写失败也不阻断原采集。

## P4 Step2 并排对照 👀
Grafana 和观测云同屏，真实请求 + k6 压测看同一时间窗。偏差在门槛内、额度可控、测试告警能触发、没有敏感字段、回退演练做过一次，才切。

## P5 Step3 回退顺序 🔁
入口切回 Grafana → 开关置关、Playbook 重跑 → 停 DataKit、移除 RUM SDK → Git 回退监控器/拨测声明（免费空间 apply 受限【待授权空间实测】）→ 轮换 Token 和 Key → 校验 Grafana。配置靠 Git 回退，数据靠原始存储。演练耗时【待实测】。
