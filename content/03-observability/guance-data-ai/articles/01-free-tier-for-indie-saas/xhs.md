# 低成本 SaaS 拼好了，还差一双眼睛

（观测云内容合作；“北京”仅指观测云免费专区）

## P1 低成本栈
Cloudflare Pages/Workers 做入口，Cloud Run 跑后端，Supabase Free 存数据。每层都有免费额度，也都有条件：Workers Free 每天 10 万请求；Cloud Run 每月有免费额度，超出按地区计费；Supabase 闲置 1 周会暂停。不是永久全免费。

## P2 可观测盲区
自建 Grafana 看得到主机和服务指标。可用户一句“登录失败”，我要翻三处后台，还看不到他浏览器里发生了什么。缺的不是指标，是一次请求的前因后果。

## P3 北京专区条件
观测云免费版：7 天循环存储，10 台主机，1 万条时间线，Trace 每天 2 万，PV 每天 5000，10 个阈值监控器，超额不再上报。需审核开通。商用须书面授权（协议 4.7）。核验日期 2026-10-27，发布前复核。

## P4 API 权益边界
免费版不支持 Open API 读写工作空间数据，也没有平台脱敏。所以普通免费空间里，Terraform 只能离线生成配置；远端建面板、建告警，要合作授权或商业空间，先确认版本、站点、权限。

## P5 GitOps / Vault / 自动化路径
AI 起草 → GitOps 放非敏感参数 → PR 审查 → Terraform plan → Playbook 部署采集配置。管理 Key、查询 Key、写入 Token 分开放 Vault、分开授权，不进仓库。
