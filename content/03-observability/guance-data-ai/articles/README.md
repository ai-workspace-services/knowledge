# 文章工作区

每个主题使用独立目录，建议命名：

```text
articles/
└── 01-vibe-coding-needs-observability/
    ├── wechat.md
    ├── xhs.md
    ├── fact-sheet.md
    └── asset-manifest.md
```

状态统一使用：`idea` → `evidence` → `outline` → `draft` → `fact-review` → `approved` → `published` → `retrospective`。

每篇发布前必须具备：

- 真实案例或实验记录；
- 官方产品事实来源与核验日期；
- 素材授权、脱敏和复用范围；
- 公众号稿、XHS 分镜及单一 CTA；
- 发布链接与一周复盘。
