# 素材工作区

建议按主题编号存放素材：

```text
assets/
├── shared/
├── 01-vibe-coding-needs-observability/
└── 02-token-to-trace/
```

每个主题素材至少记录：

- 文件名与内容说明；
- 来源、作者和取得日期；
- 是否来自本地实测、Guance 官方或客户授权；
- 是否完成用户、域名、Token、Prompt、Trace 和密钥脱敏；
- 可用于公众号、XHS、官网、销售材料或直播中的哪些范围；
- 产品版本、环境与截图日期。

禁止提交 API Key、Bearer Token、Cookie、Workspace UUID、真实用户信息、未授权客户数据和包含敏感内容的完整 Prompt。
