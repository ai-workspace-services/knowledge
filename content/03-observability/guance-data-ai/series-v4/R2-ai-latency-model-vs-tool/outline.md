# R2｜AI 调用慢，是模型慢还是工具慢？

> 状态：替补大纲（不额外增加篇数；可替换 #08）｜模板：问答拆解型｜XHS 标题：AI 慢，别急着骂模型

![agent-chain](diagrams/gif/agent-chain-wechat.gif)

## 一、场景
一次 AI 任务比平时慢很多，第一反应是“模型变慢了”，但证据呢？

## 二、知识点（问答拆解）
- Q1 慢在哪一段？把一次任务拆成模型调用、工具调用、等待三段 span
- Q2 数据进哪里？版本区分页：Agent 监测与应用性能监测共用每天 20,000 Trace
- Q3 能采什么？只采工具名、耗时、状态；不采凭据、Token 原文、完整 Prompt
- Q4 免费版可用吗？Agent Monitoring 为独立权益，须单独核验

## 三、最小实践（AI 辅助 IaC / GitOps / Playbook）
- AI 起草埋点与 Collector 过滤声明，人审 PR
- Playbook 部署，Vault 注入写入 Token；开关默认关

## 四、结果和局限
- 模型段与工具段耗时占比：【待实测】
- 免费空间 Agent 监测可用性：【待授权空间实测】

## 五、适合 / 不适合
适合：AI 任务里工具调用多的开发者。不适合：只用聊天界面、无法埋点的场景。
