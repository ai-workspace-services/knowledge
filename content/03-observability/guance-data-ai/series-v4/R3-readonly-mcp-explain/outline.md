# R3｜只给 AI 只读工具，它能解释异常吗？

> 状态：替补大纲（不额外增加篇数；可替换 #10）｜模板：动手实操型｜XHS 标题：AI 只能看不能改，还有用吗？

![least-privilege](diagrams/gif/least-privilege-wechat.gif)

## 一、场景
想让 AI 帮忙看告警，又不敢给它改配置、改代码的权限。

## 二、知识点
- 最小权限：AI 只拿查询 Key，管理 API Key 与写入 Token 分开存放、分开授权
- 免费专区 Open API 受限；OWL / MCP 为独立权益，须单独核验
- AI 只产出解释与线索，不自动修复

## 三、最小实践（AI 辅助 IaC / GitOps / Playbook）
- 只读工具声明进 Git，人审 PR；查询 Key 由 Vault 运行时注入
- 在 UAT 用一次受控异常让 AI 解释，人工对照证据

## 四、结果和局限
- 解释命中率、遗漏项：【待实测】
- 免费空间只读接口可用性：【待授权空间实测】

## 五、适合 / 不适合
适合：一个人值守、想要排障助手的人。不适合：期望 AI 自动修复生产的场景。
